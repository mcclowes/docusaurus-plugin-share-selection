# Try it

Highlight any sentence on this page to open the share palette. Try a few words, a whole paragraph, or a passage that spans a heading.

## What each button does

**Copy** puts a quote, the page and section, and a deep link on your clipboard. Paste it into Slack, Teams, or a doc and the link survives as a real link.

**Ask AI** opens ChatGPT or Claude with the passage, the heading it sits under, and the text around it, so the model knows what you're asking about.

**Copy Markdown** gives you a blockquote and a linked citation for pull requests, specs, and notes.

**Report issue** is a custom action. It opens a pre-filled GitHub issue quoting the passage you think is wrong.

## Deep links

Open a copied link in a new tab. The page scrolls to the passage and highlights it, using a text fragment on top of the nearest heading anchor.

Selections inside code blocks are ignored, because code blocks already have their own copy button:

```bash
npm install docusaurus-plugin-share-selection
```
